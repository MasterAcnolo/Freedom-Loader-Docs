# About

Freedom Loader is a free, open-source desktop application for downloading video and audio with [yt-dlp](https://github.com/yt-dlp/yt-dlp). It runs on Windows and Linux and provides a graphical interface for choosing formats, quality, output location, and other download preferences.

<a className="main-site-button" href="https://freedomloader.acnolo.fr/">Visit the main website</a>

Use the guides in this section to [install the application](./getting-started), [download media](./downloading), configure [settings and themes](./settings), use the [local HTTP API](./api), or troubleshoot a problem.

## What Freedom Loader can do

- Download video or convert audio to MP3, with a choice of quality.
- Preview video and playlist information before starting a download.
- Track progress and speed, and stop a download in progress.
- Organize playlist downloads into folders and preserve playlist order.
- Add metadata and thumbnails, and choose a preferred video codec.
- Customize the interface with built-in or community themes.

Freedom Loader uses yt-dlp and supports many sites, but availability depends on the source site and its current requirements. Only download content you are authorized to access and save, and follow the applicable laws and site terms.

## Quick start

1. Install Freedom Loader using the instructions in [Getting started](./getting-started).
2. Paste a media or playlist URL into the URL field.
3. Choose video or **Audio Only (MP3)** and select a quality.
4. Select **Download** and follow progress in the application.

Downloads are saved to the displayed folder. Use **Edit** beside the folder path to choose another location.
